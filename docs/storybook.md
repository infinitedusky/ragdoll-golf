# Storybook and the screen map

Run `npm run storybook` (port 6006); the screen map is `stories/flows/game.flow.json`, shown at `?path=/docs/game-map--docs` and drawn by `@zigbang/storybook-addon-story-flow`. To add a screen, render it from a function in `src/screens/` that both the app and a story call, add a whole-page story under `stories/` (a `.stories.jsx` that mounts it into a `<div id="app">`, title `Screens/<Name>`, so its id is `screens-<name>--default`), then add a node to the map with that story id, its address as a tag, and edges labelled with what you tap to get there; a planned screen is a node with no stories, and a screen that isn't ours (a third-party sign-in) gets `"coverage": "external"` and a `noStoryReason`. The format is in `node_modules/@zigbang/storybook-addon-story-flow/skills/story-flow-author/SKILL.md`. Story tests run with `npx vitest`.
